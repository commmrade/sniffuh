# sniffuh

`sniffuh` — учебный сырой сетевой сниффер и набор утилит вокруг него. Проект помогает разобраться, как выглядят бинарные интернет‑протоколы «на проводе», и потренироваться в работе с бинарными файлами и структурированием кода парсеров.

## Возможности
- захват кадров через `AF_PACKET` сокеты (Ethernet → ARP/IPv4/IPv6 → TCP/UDP/ICMP/TLS);
- потоковый вывод с регулируемым уровнем детализации (`--log-level 0..2`);
- запись каждого разобранного пакета в бинарный лог для последующего анализа;
- офлайн‑чтение логов с фильтрацией по адресам, портам, протоколам и времени;
- перечисление сетевых интерфейсов, чтобы быстро выбрать нужный источник трафика.

## Требования
- Linux с поддержкой сырого сокета `AF_PACKET`;
- права суперпользователя для режима захвата (`--log`);
- компилятор с поддержкой C++23, CMake ≥ 3.30;
- внешняя зависимость: [`p-ranav/argparse`](https://github.com/p-ranav/argparse) подтягивается автоматически через `FetchContent`.

## Быстрый старт
```bash
cmake -S . -B build
cmake --build build
sudo ./build/sniffuh --log --interface any -o dump.pdor --log-level 1
```

## Режимы работы CLI
- `--log` — захватывает пакеты, выводит их в stdout и складывает в файл (`-o`, по умолчанию `test.pdor`). Работает бесконечно, пока не прервать.
- `--read` — читает файл (`-i`) и выводит записи, применяя фильтры:
  - `--time-order 0|1`, `--shaddr/--thaddr`, `--eth-proto`, `--saddr/--taddr` (IPv4/IPv6), `--ip-proto`, `--sport`, `--tport`.
- `--interfaces` — печатает доступные интерфейсы. Удобно, чтобы узнать точное имя перед запуском логирования.

Примеры:
```bash
# Сниффим любой интерфейс, минимальный лог
sudo ./build/sniffuh --log -o arp-spam.pdor --log-level 0

# Ищем все TCP-пакеты от 192.168.1.10 на порт 443
./build/sniffuh --read -i arp-spam.pdor --saddr 192.168.1.10 --tport 443
```

## Структура кода
- `src/sniffer.*` — работа с сыровым сокетом, переход в promiscuous mode и чтение кадров.
- `src/parser.*` + `src/packet.hpp` — поэтапный разбор Ethernet/IP/TCP/UDP/ICMP/TLS и формирование единой структуры `Packet`.
- `src/logs.*` — форматирование вывода под разные уровни логирования и запись в JSON‑файлы.
- `src/file.*` + `include/pdor.*` — простейший стораж логов (пока JSON, далее можно заменить на двоичный формат).
- `src/utils.*` — вспомогательные функции: работа с MAC/IP, сортировки и т. д.
